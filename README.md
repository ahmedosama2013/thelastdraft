# 🕯️ THE LAST DRAFT

**THE LAST DRAFT** is a first-person horror thriller about light, darkness and an unfinished manuscript. A burned-out novelist walks into a remote pine-forest town to finish his final book, and something in the dark has begun writing the town's story for him.

## ✨ Features
* **Light is the weapon:** Burn the shadow shield off the Unwritten with your flashlight, then finish them with a flare or a streetlamp's pool of light.
* **Four chapters:** The Pine Forest, Greywater, Ottley's and Cinder Point, each with its own set pieces, from holding a gas station for fifty seconds to lighting a lighthouse beacon for the final boss.
* **Story in the margins:** Read manuscript pages that describe events slightly before they happen, and hunt for 8 optional margin notes hidden off the road.
* **Safe havens:** Streetlamps and cabin lights recharge your battery, restore your nerve and save your place.
* **Cinematic and procedural:** Raw WebGL with bloom, FXAA, fog, water and moonlight. Terrain, trees, sound and story are all generated in code.
* **Zero dependencies:** Vanilla ES modules, no build step, no downloaded assets, no CDN.

## 🎮 Controls
| Key | Action |
| --- | --- |
| W A S D, mouse | Move, look (drag with left mouse if pointer lock is unavailable) |
| Shift / Space | Sprint / jump |
| Q | Flashlight on and off |
| Hold left mouse | Focus the beam (right mouse works in every mode) |
| F | Throw a flare |
| R | Swap in a spare battery |
| E | Read a page, hold to operate things |
| M / Esc | Mute / pause |

Best with headphones, in a dark room.
